# 에이전트 메모리 시스템 — 구조와 2026년 증거 상태

리서치 범위: 7개 에이전트 병렬, 3웨이브. arXiv·벤더 엔지니어링 블로그·GitHub·HN.
전체 원자료는 `journal.md`, 미추적 실마리는 `leads.md`.

## 한 줄 결론

메모리의 문법(적고 · 고르고 · 정리하고)은 2023년에 정해졌고, 2026년의 진짜 뉴스는 구조가 아니라
**증거**다. 세 가지가 독립적으로 확인된다.

1. **가장 강한 기준선은 늘 "아무것도 안 하기"였다.** 전체 대화를 그냥 넣기, `grep`, 평범한 RAG가
   전문 메모리 제품을 자기들 벤치마크에서 이긴다.
2. **병목은 검색이 아니라 쓰기다.** 그리고 쓰기를 채점하는 공유 계측기가 존재하지 않는다.
3. **메모리는 회수 능력을 올리면서 판단력을 떨어뜨린다.** 둘은 현재 프론티어에서 음의 상관이다.

코딩 에이전트는 메모리가 **가장 안 듣는** 도메인이면서, 동시에 테스트라는 강한 오라클 덕분에
**유일하게 믿을 만한 측정이 가능한** 도메인이다.

## 인용하면 안 되는 숫자

- **LoCoMo 기반 모든 수치.** 정답의 6.4%가 오염돼 있고 이론적 상한이 93.6%이며,
  심판이 의도적으로 틀린 답의 62.81%를 통과시킨다.
- **LongMemEval-S 기반 수치.** ~115K 토큰이라 현대 컨텍스트 창에 통째로 들어간다.
- **벤더 자가보고 전부.** 같은 시스템(Zep)이 84 → 75.14 → 65.99 → 58.44%로 채점됐다.
- 이 분야의 모든 리더보드는 이해관계자가 운영한다.

## 우리(sasu 하네스)에게 주는 함의

1. **"물어보고 저장"이 기본값이어야 한다.** 자동 추출 정밀도 0.42, 확인 비용 0.
2. **침묵을 신호로 쓰면 안 된다.** AI가 아무 말 안 하면 사람은 검토를 건너뛴다(18건 중 9건).
3. **판단을 훅에 넣지 말고 이미 문맥을 가진 에이전트에게 남겨라.** 단 깨우는 것 자체가 비용이다.
4. **저장한다면 추상화된 규칙 한 번, 트레이스는 절대.** 저수준 트레이스는 음의 전이를 유발한다.
5. **근거(why)를 함께 저장하라.** 근거 없는 규칙은 삭제 비용이 O(2^n)이 되어 영원히 남는다.
6. **낡은 규칙은 고치지 말고 지워라.** 틀린 표준은 침묵보다 나쁘다(0% vs 33%).
7. **거부는 제거가 아니다.** 강한 모델이 악성/낡은 규칙을 거부해도 파일에는 96.7% 존속한다.
